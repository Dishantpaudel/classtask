# classtask

Android (Jetpack Compose) Unsplash gallery. Session 8 homework: photo details screen
wired to the Unsplash API (`GET /photos/{id}`).

## Setup

API key is **not** committed. Add yours to `local.properties`:

```
unsplash.access.key=YOUR_UNSPLASH_ACCESS_KEY
```

Get a key at https://unsplash.com/oauth/applications, then build & run.
